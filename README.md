Mona here. I'm done preparing your exercise. Hope you enjoy! 💚

This exercise is about using GitHub Copilot CLI and a coordinated team of custom agents to build a small Project Pulse dashboard for Mona's team. The goal is to plan, design, implement, and validate a lightweight project overview that shows active work, owners, statuses, recent activity, and priority information.

The repo gives you a prebuilt agent team in `.github/agents/` and walks you through the orchestration flow: the Orchestrator delegates work, the Planner maps implementation phases, the Designer shapes the dashboard experience, and the Coder builds the static app and launch config.

Remember, it's self-paced so feel free to take a break! ☕️
